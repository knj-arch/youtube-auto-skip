아직 완료되지 않은 항목
• 실제 YouTube 광고에서 건너뛰기 성공 확인 — 버전 1.0.0은 실제 광고 테스트에서 실패했습니다. 실제 15초 광고 2개에서 '건너뛰기' 버튼이 나타났고 자동 클릭 11회가 기록됐지만, 광고는 각각 끝까지 재생됐습니다. 본문 재생 복귀는 광고 자연 종료이며 건너뛰기 성공으로 판정하지 않습니다.
• 현재 공개 YouTube 플레이어의 실제 건너뛰기 처리기는 event.isTrusted가 false인 스크립트 클릭을 무시합니다. 따라서 테스트용 페이지의 11개 기능 검증 통과만으로 현재 실제 YouTube에서의 동작을 입증할 수 없습니다.
• 별도 실제 15.021초 광고의 같은 버튼에서 기존 자동 click 및 합성 mousedown/mouseup/click은 실패했습니다. 실제 브라우저 입력 클릭(isTrusted=true)은 광고 9.200초에 눌렸고 27ms 뒤 광고가 해제되어 본문 재생으로 복귀했습니다. 이 비교 입력은 테스트 도구가 보낸 것으로 버전 1.0.0의 자동 동작이 아닙니다.
• Chrome debugger 권한을 사용하는 별도 실험 확장은 테스트용 페이지에서 isTrusted=true 클릭 및 9ms 안의 attach/detach를 확인했습니다. 실제 YouTube에서는 건너뛰기 버튼 없는 광고만 나와 이 실험 확장의 실제 광고 자동 성공은 아직 미검증입니다. 실험 코드와 추가 권한은 제출한 버전 1.0.0에 반영되지 않았습니다.
