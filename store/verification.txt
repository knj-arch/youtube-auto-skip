검증 상태 — 2026-10-13

버전 1.0.1
• storage + debugger 권한의 실제 MV3 확장을 별도 Chromium 프로필에 로드하고 manifest 오류 0개 확인
• 브라우저 입력 방식의 실제 YouTube 광고 자동 건너뛰기 성공 1건 확인
  - 실제 광고 길이 31.001초, 광고 5.228초에 확장의 worker 요청과 연결된 isTrusted=true 클릭
  - 광고가 25.773초 남은 시점이므로 자연 종료와 구별됨
  - 클릭 37ms 뒤 광고 상태 해제, 본문 263.241초 영상이 0.104초에서 2.205초로 진행
  - 테스트 도구의 외부 건너뛰기 클릭 또는 직접 CDP 입력은 사용하지 않음
• 이후 홈→영상 SPA 요청과 닫힌 탭 정리 처리를 보완한 최종 파일로 실제 Chromium 통합 검증 13개 통과
  - 3종 버튼의 trusted 입력, 숨김·비활성·가림·다른 경로·비활성 탭 차단, SPA 이동, 설정 저장/전파, 클릭 간격, debugger 해제
• 최종 worker 동작 mock 17개 + 배포 동작 mock 14개 = 31개 통과
• 최종 파일의 추가 실제 YouTube 탐색에서 실행 중 worker 함수와 디스크 소스 일치 확인
  - 실제 광고는 나왔지만 건너뛰기 버튼이 없었으므로 최종 해시의 추가 실제 광고 자동 성공으로 판정하지 않음
  - 앞선 실제 성공 증거와 최종 파일의 통합 검증을 구분해 기록
• 새 권한 고지를 포함한 실제 팝업 캡처와 키보드·설정 유지·고대비 UI 확인
• 스토어 ZIP 1.0.1 생성, background.js 포함 runtime 10개 및 최상위 manifest 확인
• 추가 권한의 Chrome 경고와 실제 동작 범위를 팝업·README·개인정보 처리방침·스토어 설명에 반영

실패 이력 — 버전 1.0.0
• 실제 15초 광고 2개에서 자동 click 11회가 기록됐지만 각각 끝까지 재생됨
• 실제 YouTube 플레이어는 event.isTrusted=false인 스크립트 클릭을 무시함
• 같은 실제 광고 버튼의 브라우저 입력 비교는 광고 9.200/15.021초에서 27ms 뒤 광고 종료로 성공
• 테스트용 페이지의 이전 11개 기능 검증 통과는 실제 광고 성공을 입증하지 않았음
