유튜브 자동 건너뛰기

개인정보 처리방침

적용 버전 1.0.5 계열 · 최종 업데이트 2026년 10월 28일 (Asia/Seoul)

이 확장 프로그램은 현재 보고 있는 Chrome 창의 활성 YouTube 영상 탭에서 광고를 감지하면 설정한 한도까지 최소 3초 간격으로 새로고침합니다. 한도는 기본 3회이며 사용자가 1~10회로 바꿀 수 있습니다. 한도를 다 쓴 뒤에도 광고가 계속되면 화면에 표시되고 클릭 가능한 건너뛰기 버튼을 자동으로 누릅니다. 기능에 필요한 탭 상태, 페이지 요소, 임시 영상 상태와 설정을 사용자의 기기 안에서 처리합니다. 새로고침이 광고를 없애거나 본영상 재생을 보장하지는 않습니다.

1.0.5는 광고·버튼 변화에 대한 감지 반응을 개선한 버전입니다. 추가 권한이나 데이터 처리 범위 변경은 없으며 아래 설정·임시 상태·선택적 진단 정책을 유지합니다.

처리하는 정보와 사용 목적

  • 대상 탭 정보: 현재 탭의 주소, 활성 여부와 창의 초점 상태를 확인하여 현재 보고 있는 https://www.youtube.com/watch 영상 페이지인지 판단합니다. 이 정보로 방문 기록 목록을 만들거나 저장하지 않습니다.
  • YouTube 플레이어 및 버튼 상태: 플레이어와 건너뛰기 버튼의 DOM 요소, 광고 재생 여부, 버튼의 표시·활성 상태와 화면 좌표를 확인합니다. 광고 감지 후 새로고침하거나, 광고가 계속될 때 사용 가능한 건너뛰기 버튼에 Chrome Debugger의 마우스 입력을 전달하는 데 사용합니다.
  • 현재 영상의 임시 상태: 탭별 현재 영상 ID, 자동 새로고침 시도 횟수·간격 정보와 선택적인 본영상 재생 위치를 chrome.storage.session에 보관합니다. 설정한 새로고침 한도와 간격을 지키고, 새로고침 후 같은 본영상의 마지막 확인 위치로 복원을 시도하는 데 사용합니다. 확장 프로그램만 접근할 수 있는 Chrome 세션 메모리이며 방문 영상 목록으로 누적하지 않습니다.
  • 기능 설정: 켜기/끄기(enabled 불리언)와 최대 새로고침 횟수(maxReloads, 1~10 사이의 정수이며 기본값 3)를 chrome.storage.local에 저장합니다. 현재 기기의 Chrome 프로필에서 사용하며 확장 프로그램이 이 값을 서버에 전송하거나 기기 간 동기화하지 않습니다.
  • 작동 상태 진단: 사용자가 팝업에서 상태 확인을 누르면 확장 프로그램 버전, 브라우저 종류·버전, 현재 탭·콘텐츠 스크립트의 연결·광고·표시·초점 상태, 플레이어·버튼 개수, 누적 새로고침 횟수와 최근 자동 처리 결과·사유·경과 시간을 기기 안에서 확인합니다. 진단 결과에는 URL, 페이지 제목, 영상 ID와 전체 사용자 에이전트 문자열을 넣지 않습니다.

탭 정보, 페이지 요소, 버튼 좌표와 클릭 간격 정보는 실행 중 메모리에서 처리합니다. 현재 영상의 임시 상태도 세션 메모리에만 보관하며 영구 클릭 로그, 방문 기록 또는 시청 기록으로 저장하지 않습니다. 영상 내용, 자막, 계정 정보, 쿠키, 로그인 정보, 결제 정보를 수집하거나 저장하는 기능은 없습니다. 사용자의 마우스·키보드 입력을 기록하거나 추적하지 않습니다.

전송, 공유 및 추적

확장 프로그램에는 별도의 서버, 분석 도구, 광고 추적 도구 또는 사용자 데이터를 외부로 전송하는 코드가 없습니다. 처리하는 정보를 개발자나 제삼자에게 보내거나 판매하지 않습니다. 개인 맞춤 광고, 사용자 행동 분석, 신용도 판단 또는 대출 관련 용도로 사용하지 않습니다.

페이지를 새로고침하거나 건너뛰기 버튼을 누르면 YouTube 사이트 자체의 처리와 통신이 발생할 수 있습니다. YouTube, Chrome, Chrome 웹 스토어 및 이 문서를 제공하는 호스팅 서비스의 데이터 처리는 각 서비스의 정책에 따릅니다. 이 문서는 확장 프로그램 자체의 데이터 취급을 설명합니다.

선택적인 진단과 결과 복사

팝업의 ‘작동하지 않을 때’ 영역은 기본으로 접혀 있습니다. 사용자가 ‘상태 확인’을 눌렀을 때만 읽기 전용 진단을 요청하며, 이 요청이 새로고침이나 건너뛰기를 실행하지는 않습니다. 결과는 정해진 필드와 제한된 값으로 구성해 팝업에 표시합니다.

‘결과 복사’를 누르면 표시한 진단 결과를 클립보드에 복사합니다. 자동 복사가 차단되면 결과를 직접 선택해 복사할 수 있습니다. 확장 프로그램이 결과를 개발자나 외부 서버에 자동으로 전송하지 않습니다. 복사한 결과는 사용자가 관리하는 클립보드에 남을 수 있으며 이후 붙여넣기·공유 여부는 사용자가 선택합니다.

보관 및 삭제

켜기/끄기와 최대 새로고침 횟수 설정은 사용자가 변경하거나 확장 프로그램의 로컬 데이터를 삭제할 때까지 해당 Chrome 프로필의 기기에 보관됩니다. 확장 프로그램을 제거하면 Chrome이 확장 프로그램의 로컬 저장 데이터를 삭제합니다. 실행 중 필요한 탭 정보, 페이지 요소, 버튼 좌표와 클릭 간격 정보는 처리 중 메모리에서만 유지하며 디스크에 기록하지 않습니다.

현재 영상 ID, 새로고침 횟수·간격 정보와 선택적인 본영상 재생 위치는 해당 탭의 현재 영상 상태로만 보관합니다. 위치 복원이 완료되면 저장한 재생 위치는 삭제하고, 새로고침 횟수는 같은 영상을 보는 동안 유지합니다. 다른 영상으로 이동하면 새 영상의 상태로 바뀝니다. 탭을 닫으면 삭제하며, Chrome을 다시 시작하거나 확장 프로그램을 업데이트·다시 로드하면 chrome.storage.session의 임시 상태도 삭제됩니다.

최근 자동 처리 결과는 탭마다 한 건만 백그라운드 worker의 실행 메모리에 보관하며, 현재 문서의 최근 결과도 콘텐츠 스크립트 메모리에서만 유지합니다. 디스크에 기록하거나 결과 이력을 누적하지 않습니다. 탭을 닫거나 worker가 종료·재시작되면 해당 worker 메모리의 결과가 사라지고, 콘텐츠 스크립트 결과는 문서의 수명에 따라 사라집니다. 팝업에서 만든 진단 결과도 팝업 실행 메모리에서만 처리합니다.

팝업의 스위치를 끄면 자동 새로고침, 재생 위치 복원과 건너뛰기를 중지할 수 있습니다. 확장 프로그램을 제거하면 이후의 페이지 요소 처리도 중지됩니다.

권한

storage 권한은 켜기/끄기·최대 새로고침 횟수 설정 저장과 새로고침 한도·간격 확인 및 재생 위치 복원을 위한 세션 상태 보관에 사용합니다. https://www.youtube.com/*의 콘텐츠 스크립트는 광고 플레이어와 건너뛰기 버튼을 감지합니다. 자동 새로고침, 재생 위치 복원과 버튼 클릭 대상은 현재 보고 있는 Chrome 창의 활성 YouTube 영상(/watch) 탭으로 제한합니다.

debugger 권한은 클릭을 처리할 때 대상 YouTube 탭에 잠시 연결하여 버튼 상태와 위치를 다시 확인하고 Chrome이 제공하는 마우스 입력을 전달하는 데 사용합니다. 클릭 처리가 끝나면 연결을 해제합니다. 네트워크 트래픽, 쿠키 또는 계정 정보를 읽는 데 사용하지 않습니다.

이 권한 자체는 범위가 넓습니다. Chrome은 페이지 디버거 접근과 모든 웹사이트의 데이터 읽기·변경 경고를 표시할 수 있습니다. 권한 자체가 YouTube에 한정되는 것은 아니며, 확장 프로그램 코드에서 사용 대상을 위 영상 탭으로 제한합니다. 연결 중 Chrome의 디버깅 알림이 잠시 표시될 수 있습니다. 실행 코드는 확장 프로그램 패키지 안에 포함됩니다.

데이터 사용 범위

유튜브 자동 건너뛰기의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책과 제한된 사용 요건을 따릅니다. 필요한 탭 정보, 페이지 요소와 설정은 공개된 자동 건너뛰기 기능을 제공하는 데만 사용하며, 개발자가 사용자의 페이지 내용이나 시청 활동을 열람할 수 있도록 전송하는 기능은 없습니다.

문의 및 변경 안내

GitHub 저장소의 문의 게시판에서 문의할 수 있습니다. 스토어 게시 후에는 Chrome 웹 스토어의 확장 프로그램 상세 페이지에 제공된 지원 기능도 사용할 수 있습니다. 기능이나 데이터 처리 방식이 바뀌면 이 문서와 스토어의 개인정보 공개 내용을 함께 업데이트합니다.

이 확장 프로그램은 독립적으로 만든 도구이며 YouTube 또는 Google이 제공하거나 보증하는 제품이 아닙니다.
