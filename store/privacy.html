유튜브 자동 건너뛰기

개인정보 처리방침

적용 버전 1.0.0 계열 · 최종 업데이트 2026년 10월 13일 (Asia/Seoul)

이 확장 프로그램은 유튜브 광고의 건너뛰기 버튼이 화면에 나타나고 클릭할 수 있을 때 자동으로 누릅니다. 기능에 필요한 페이지 요소와 설정을 사용자의 기기 안에서 처리합니다.

처리하는 정보와 사용 목적

  • YouTube 플레이어 및 버튼 상태: https://www.youtube.com/*에서 플레이어와 건너뛰기 버튼의 DOM 요소, 광고 재생 여부, 버튼의 표시·활성 상태를 확인합니다. 광고가 재생 중이고 사용 가능한 건너뛰기 버튼을 자동으로 누르는 데만 사용합니다.
  • 기능 켜기/끄기 설정: 선택한 상태를 chrome.storage.local에 불리언 값 한 개로 저장합니다. 현재 기기의 Chrome 프로필에서 사용하며 확장 프로그램이 이 값을 서버에 전송하거나 기기 간 동기화하지 않습니다.

페이지 요소와 클릭 간격 정보는 실행 중 메모리에서만 처리합니다. 방문 기록 또는 시청 기록으로 저장하지 않습니다. 영상 내용, 자막, 계정 정보, 쿠키, 로그인 정보, 결제 정보를 수집하거나 저장하는 기능은 없습니다.

전송, 공유 및 추적

확장 프로그램에는 별도의 서버, 분석 도구, 광고 추적 도구 또는 사용자 데이터를 외부로 전송하는 코드가 없습니다. 처리하는 정보를 개발자나 제삼자에게 보내거나 판매하지 않습니다. 개인 맞춤 광고, 사용자 행동 분석, 신용도 판단 또는 대출 관련 용도로 사용하지 않습니다.

건너뛰기 버튼을 누르면 YouTube 사이트 자체의 처리와 통신이 발생할 수 있습니다. YouTube, Chrome, Chrome 웹 스토어 및 이 문서를 제공하는 호스팅 서비스의 데이터 처리는 각 서비스의 정책에 따릅니다. 이 문서는 확장 프로그램 자체의 데이터 취급을 설명합니다.

보관 및 삭제

켜기/끄기 설정은 사용자가 변경하거나 확장 프로그램의 로컬 데이터를 삭제할 때까지 해당 Chrome 프로필의 기기에 보관됩니다. 확장 프로그램을 제거하면 Chrome이 확장 프로그램의 로컬 저장 데이터를 삭제합니다. 실행 중인 페이지 요소와 클릭 간격 정보는 페이지를 다시 불러오거나 해당 탭을 닫으면 더 이상 유지되지 않습니다.

팝업의 스위치를 끄면 자동 건너뛰기 기능을 중지할 수 있습니다. 확장 프로그램을 제거하면 이후의 페이지 요소 처리도 중지됩니다.

권한

storage 권한은 켜기/끄기 설정 저장에 사용합니다. https://www.youtube.com/* 접근은 페이지에 포함된 플레이어와 건너뛰기 버튼을 확인하고 누르는 데 사용합니다. 다른 사이트에 콘텐츠 스크립트를 실행하지 않습니다. 실행 코드는 확장 프로그램 패키지 안에 포함됩니다.

유튜브 자동 건너뛰기의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책과 제한된 사용 요건을 따릅니다. 필요한 페이지 요소와 설정은 공개된 자동 건너뛰기 기능을 제공하는 데만 사용하며, 개발자가 사용자의 페이지 내용이나 시청 활동을 열람할 수 있도록 전송하는 기능은 없습니다.
