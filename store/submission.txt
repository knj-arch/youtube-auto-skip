유튜브 자동 건너뛰기 · 버전 1.0.0
작성일: 2026-10-13 (Asia/Seoul)

스토어 이름
유튜브 자동 건너뛰기

짧은 설명
유튜브 광고의 건너뛰기 버튼이 나타나면 자동으로 클릭합니다.

상세 설명
유튜브에서 광고의 건너뛰기 버튼이 나타났을 때 직접 누르는 수고를 줄여줍니다. 광고가 재생 중인 플레이어에서 화면에 표시되고 클릭 가능한 건너뛰기 버튼을 찾아 자동으로 누릅니다.

• Chrome 도구 모음의 확장 프로그램 팝업에서 켜기/끄기를 바꿀 수 있습니다.
• 켜기/끄기 설정은 현재 Chrome 프로필의 기기에 저장됩니다.
• https://www.youtube.com/ 에서 작동합니다.
• 건너뛰기 버튼이 없는 광고는 그대로 재생됩니다.
• YouTube 화면 구조가 변경되면 기능이 작동하지 않을 수 있습니다.

확장 프로그램은 광고 상태와 건너뛰기 버튼을 확인하기 위해 페이지의 플레이어 및 버튼 요소를 기기 안에서 읽습니다. 시청 기록, 계정 정보, 쿠키를 수집하거나 개발자에게 전송하는 기능은 없습니다. 회원가입과 구독 결제 없이 사용할 수 있습니다.

이 확장 프로그램은 독립적으로 만든 도구이며 YouTube 또는 Google이 제공하거나 보증하는 제품이 아닙니다.

단일 목적 설명 (Single purpose)
유튜브 광고가 재생 중일 때 화면에 표시되고 클릭 가능한 건너뛰기 버튼을 자동으로 눌러 사용자의 반복적인 클릭을 줄입니다. 사용자는 팝업에서 이 기능을 켜거나 끌 수 있습니다.

storage 권한 사용 이유
사용자가 선택한 자동 건너뛰기 켜기/끄기 설정을 chrome.storage.local에 저장하고 읽기 위해 필요합니다. 저장하는 값은 enabled라는 불리언 설정 한 개이며, 사용자 계정이나 시청 기록을 저장하지 않습니다. 기기 간 설정 동기화에는 사용하지 않습니다.

https://www.youtube.com/* 사이트 접근 사용 이유
YouTube 페이지에 콘텐츠 스크립트를 실행하여 광고 재생 상태와 건너뛰기 버튼의 표시·활성 상태를 확인하고 클릭하기 위해 필요합니다. 접근 범위는 https://www.youtube.com/* 이며, 다른 사이트에는 스크립트를 실행하지 않습니다. manifest의 content_scripts.matches에 선언된 접근 범위입니다.

원격 코드 (Remote code)
아니요 / No, I am not using remote code.
JavaScript는 확장 프로그램 패키지에 포함됩니다. 외부 서버에서 코드를 내려받아 실행하는 기능이 없습니다.

개인정보 처리방침 URL
https://knj-arch.github.io/youtube-auto-skip/
이 주소는 main push 후 GitHub Pages에서 store/privacy.html을 게시합니다. 로그인 없이 열리는지 확인한 뒤 대시보드에 입력하세요. 로컬 파일 경로나 ZIP 다운로드 주소를 처리방침 주소로 입력하지 마세요.

데이터 사용 공개 항목 권고
현재 버전 1.0.0 코드와 공식 FAQ를 기준으로 한 작성 제안입니다. Google FAQ는 기기 안에서만 처리하는 사용자 데이터도 공개하도록 안내합니다. 외부 전송이 없다는 이유로 모든 항목을 해제하지 마세요.

• 웹사이트 콘텐츠 (Website content): 체크 권고. 플레이어와 건너뛰기 버튼의 DOM 요소, 광고 여부, 표시·활성 상태를 로컬에서 읽어 자동 클릭 기능에 사용합니다. 영상 내용이나 자막을 저장하거나 전송하는 기능은 없습니다. 필요한 UI 상태를 로컬에서만 처리한다는 내용을 처리방침에 공개합니다.
• 웹 기록 (Web history): 현재 구현은 방문 URL 목록이나 시청 기록을 기록하지 않으므로 체크하지 않는 것으로 작성할 수 있습니다. YouTube에 스크립트가 실행된다는 사실만으로 방문 기록 저장 기능이 생기지는 않습니다.
• 사용자 활동 (User activity): 현재 구현은 클릭·키 입력·마우스·스크롤 활동을 기록하거나 추적하지 않으므로 체크하지 않는 것으로 작성할 수 있습니다. 버튼 자동 클릭 기능 자체와 사용자 활동 기록 수집을 구분합니다.
• 개인 식별 정보, 건강 정보, 금융 및 결제 정보, 인증 정보, 개인적인 커뮤니케이션, 위치: 현재 구현은 해당 정보를 읽거나 수집·저장·전송하지 않으므로 체크하지 않는 것으로 작성할 수 있습니다.
• enabled 설정: 기능 제공에 필요한 불리언 값 한 개를 chrome.storage.local에 저장합니다. 계정이나 사용자 식별자와 연결하지 않으며, 위 공개 항목의 개인정보 유형에는 해당하지 않습니다. 처리방침에는 저장 사실을 기재합니다.

실제 대시보드의 항목 설명이 달라졌거나 코드를 변경했다면 해당 정의와 최종 동작을 확인하여 수정하세요. 이 항목들은 심사 결과를 보장하지 않습니다.

데이터 사용 확인 문항
현재 패키지에는 사용자 데이터를 판매하거나 기능과 무관하게 전송하는 코드, 신용도 판단·대출 관련 용도로 사용하는 코드가 없습니다. 게시자는 실제 운영과 지원 업무를 포함하여 각 확인 문항이 사실인지 확인한 뒤 직접 체크해야 합니다. 코드 검토만으로 게시자 본인의 외부 운영 관행을 대신 인증할 수는 없습니다.

심사 참고 메모
광고가 재생 중인 플레이어 내부의 표시되고 활성화된 건너뛰기 버튼만 클릭합니다. 화면에 아직 표시되지 않았거나 사용할 수 없는 버튼은 클릭하지 않습니다. 팝업에서 끄면 자동 클릭을 중지합니다.
실제 YouTube 광고에서 검증 완료했다고 기재하지 마세요. 제출 전에 실제 광고에서 동작을 확인하고 최종 패키지 버전과 스크린샷이 일치하는지 확인하세요.

게시자가 직접 입력할 정보
• 실제 게시자 이름 또는 표시 이름
• 연락 가능한 이메일 및 계정 확인 정보
• 공개된 개인정보 처리방침 HTTPS 주소
• 실제 지원 연락처 또는 지원 URL을 사용하려는 경우 해당 주소
이 문서에는 임의의 신원, 이메일, 공개 URL을 넣지 않았습니다.
