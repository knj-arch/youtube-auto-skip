스토어 이름
유튜브 자동 건너뛰기

짧은 설명
유튜브 광고를 감지하면 설정한 횟수만큼 새로고침하고, 광고가 계속되면 건너뛰기 버튼을 자동으로 누릅니다.

상세 설명
유튜브에서 광고가 나오면 설정한 횟수까지 최소 3초 간격으로 새로고침합니다. 한도를 다 쓴 뒤에도 광고가 나오면 화면에 표시되고 클릭 가능한 건너뛰기 버튼을 기다렸다가 자동으로 누릅니다. 기본 새로고침 한도는 3회이며 팝업에서 1~10 사이의 정수로 설정할 수 있습니다. 새로고침으로 광고가 사라지거나 본영상으로 넘어가는 것을 보장하지는 않으며, 광고가 다시 나오거나 더 길어질 수 있습니다.

• Chrome 도구 모음의 확장 프로그램 팝업에서 켜기/끄기를 바꿀 수 있습니다.
• 팝업에서 영상당 최대 새로고침 횟수를 1~10회로 바꿀 수 있습니다. 기본값은 3회이며 변경하면 자동 저장돼 다음 시도부터 적용됩니다.
• 시도 횟수는 같은 탭의 현재 영상에 누적됩니다. 본영상으로 돌아와도 누적 횟수는 유지하며 새 영상으로 이동하면 새 한도를 사용합니다. 설정한 한도를 늘리면 같은 영상에서도 추가로 시도할 수 있습니다.
• 켜기/끄기와 새로고침 횟수 설정은 현재 Chrome 프로필의 기기에 저장됩니다.
• 현재 보고 있는 Chrome 창의 활성 https://www.youtube.com/watch 영상 탭에서 작동합니다.
• 다른 탭이나 다른 프로그램을 보고 있을 때는 자동 새로고침이나 클릭을 하지 않습니다.
• 건너뛰기 버튼이 없는 광고도 한도까지 새로고침을 시도하며, 한도를 다 쓴 뒤에도 버튼이 없으면 그대로 재생됩니다.
• 광고가 아닌 구간에서 마지막으로 확인한 본영상 재생 위치가 있으면, 새로고침 후 같은 본영상으로 돌아왔을 때 복원을 시도합니다. 라이브 영상이나 재생 길이가 불명확한 경우에는 생략합니다.
• YouTube 화면 구조가 변경되면 기능이 작동하지 않을 수 있습니다.

확장 프로그램은 대상 영상 탭인지 확인하기 위한 현재 탭의 주소·활성 상태, 광고 플레이어와 버튼의 상태·좌표 및 본영상 재생 위치를 기기 안에서 처리합니다. 탭별 현재 영상 ID, 새로고침 시도 횟수·간격 정보와 선택적인 본영상 재생 위치는 확장 프로그램만 접근할 수 있는 Chrome 세션 메모리에 임시 보관합니다. 새로고침 한도를 지키고 재생 위치 복원을 시도하는 데 사용하며, 탭을 닫거나 Chrome을 다시 시작하거나 확장 프로그램을 업데이트·다시 로드하면 삭제됩니다. 위치 복원이 완료되면 저장한 위치는 삭제하고 시도 횟수는 같은 영상을 보는 동안 유지합니다. 방문 영상 목록이나 영구 클릭 로그로 누적하지 않습니다. 계정 정보와 쿠키를 수집하거나 데이터를 개발자에게 전송하는 기능은 없습니다. 회원가입과 구독 결제 없이 사용할 수 있습니다.

이 기능에는 debugger 권한이 필요합니다. Chrome은 페이지 디버거 접근 및 모든 웹사이트의 데이터 읽기·변경 경고를 표시할 수 있습니다. 권한 자체의 범위는 넓지만, 이 확장 프로그램의 코드는 현재 보고 있는 YouTube 영상 탭만 대상으로 제한합니다. 클릭 처리 중 Chrome의 디버깅 알림이 잠시 표시될 수 있습니다.

이 확장 프로그램은 독립적으로 만든 도구이며 YouTube 또는 Google이 제공하거나 보증하는 제품이 아닙니다.

단일 목적 설명 (Single purpose)
현재 보고 있는 Chrome 창의 활성 YouTube 영상 탭에서 광고를 감지하면 설정한 한도까지 새로고침하고, 한도를 다 쓴 뒤에도 광고가 계속되면 화면에 표시되고 클릭 가능한 건너뛰기 버튼을 자동으로 눌러 광고 중단에 필요한 수동 조작을 줄입니다. 새로고침 후 본영상으로 돌아오면 마지막으로 확인한 본영상 재생 위치 복원을 시도합니다. 사용자는 팝업에서 이 기능을 켜거나 끄고 최대 새로고침 횟수를 설정할 수 있습니다.

storage 권한 사용 이유
사용자가 선택한 켜기/끄기(enabled 불리언)와 최대 새로고침 횟수(maxReloads 정수 1~10, 기본 3) 설정을 chrome.storage.local에 저장하고 읽습니다. chrome.storage.session에는 탭별 현재 영상 ID, 새로고침 시도 횟수·간격 정보와 선택적인 본영상 재생 위치를 임시 보관하여 새로고침 한도를 지키고 재생 위치 복원을 시도합니다. 위치 복원이 완료되면 저장한 위치는 삭제하고 시도 횟수는 같은 영상을 보는 동안 유지합니다. 세션 상태는 확장 프로그램만 접근하는 메모리에 보관하며 탭을 닫거나 Chrome을 다시 시작하거나 확장 프로그램을 업데이트·다시 로드하면 삭제됩니다. 방문 영상 목록이나 시청 기록으로 누적하지 않고 사용자 계정과 연결하거나 기기 간 동기화하지 않습니다.

https://www.youtube.com/* 사이트 접근 사용 이유
YouTube 페이지에 콘텐츠 스크립트를 실행하여 광고 재생 상태와 건너뛰기 버튼의 표시·활성 상태, 본영상 재생 위치를 확인하기 위해 필요합니다. 콘텐츠 스크립트 범위는 https://www.youtube.com/* 이며 다른 사이트에는 실행하지 않습니다. 자동 새로고침, 재생 위치 복원과 버튼 클릭은 현재 보고 있는 Chrome 창의 활성 https://www.youtube.com/watch 영상 탭으로 제한합니다. manifest의 content_scripts.matches에 선언된 접근 범위입니다.

debugger 권한 사용 이유
유튜브의 건너뛰기 버튼은 일반 JavaScript의 element.click() 입력을 무시할 수 있으므로, Chrome Debugger API를 통해 브라우저가 생성한 마우스 입력을 전달하기 위해 필요합니다. 현재 보고 있는 Chrome 창의 활성 https://www.youtube.com/watch 탭에서 광고가 재생 중이고 화면에 표시되며 클릭 가능한 건너뛰기 버튼의 상태와 위치를 확인한 뒤 Input.dispatchMouseEvent로 해당 위치에 마우스 누르기·떼기 입력을 보냅니다. 클릭 처리를 위해 해당 탭에 잠시 연결하고 작업이 끝나면 연결을 해제합니다. 다른 사이트나 백그라운드 탭에는 클릭하지 않습니다. 네트워크 감시, 쿠키·계정 정보 읽기 또는 영구 로그 수집에는 사용하지 않습니다.

debugger 권한은 Chrome의 페이지 디버거 접근 및 모든 웹사이트의 데이터 읽기·변경 경고를 유발할 수 있는 넓은 권한입니다. 이 경고를 숨기거나 권한 자체가 YouTube로 한정된다고 설명하지 않습니다. 실제 코드에서 탭 주소·활성 여부·창 초점과 건너뛰기 버튼 상태를 확인하여 위 용도로 사용을 제한합니다.

데이터 사용 공개 항목 권고
현재 버전 1.0.2의 데이터 처리와 공식 FAQ를 기준으로 한 작성 제안입니다. Google FAQ는 기기 안에서만 처리하는 사용자 데이터도 공개하도록 안내합니다. 외부 전송이 없다는 이유로 모든 항목을 해제하지 마세요. debugger 권한 자체의 광범위한 기능과 현재 코드가 실제로 처리하는 데이터를 구분해 작성합니다.

• 웹사이트 콘텐츠 (Website content): 체크 권고. 플레이어와 건너뛰기 버튼의 DOM 요소, 광고 여부, 표시·활성 상태, 좌표와 본영상 재생 위치를 로컬에서 읽어 새로고침·위치 복원·버튼 클릭에 사용합니다. 영상 내용이나 자막을 저장하거나 전송하는 기능은 없습니다.
• 웹 기록 (Web history): 체크 권고. 현재 탭의 URL을 읽고, 탭별 현재 영상 ID를 세션 메모리에 임시 보관합니다. 설정한 새로고침 한도를 지키고 본영상 재생 위치 복원을 시도하는 데 사용합니다. 방문 URL·영상 목록이나 장기 시청 기록으로 누적하지 않는다는 사실과 임시 상태의 삭제 시점을 처리방침에 공개합니다.
• 사용자 활동 (User activity): 사용자의 클릭·키 입력·마우스·스크롤 활동을 기록하거나 추적하는 기능은 없습니다. 본영상 재생 위치를 임시로 처리하는 사실은 위 문구와 처리방침에 공개했습니다. 제출할 때 실제 대시보드의 사용자 활동 정의와 최종 코드에 맞춰 해당 항목도 확인합니다.
• 개인 식별 정보, 건강 정보, 금융 및 결제 정보, 인증 정보, 개인적인 커뮤니케이션, 위치: 현재 구현은 해당 정보를 읽거나 수집·저장·전송하지 않으므로 체크하지 않는 것으로 작성할 수 있습니다.
• enabled 및 maxReloads 설정: 기능 제공에 필요한 켜기/끄기 불리언과 최대 새로고침 횟수 정수를 chrome.storage.local에 저장합니다. 계정이나 사용자 식별자와 연결하지 않으며, 위 공개 항목의 개인정보 유형에는 해당하지 않습니다. 처리방침에는 저장 사실을 기재합니다.
• 임시 영상 상태: 탭별 현재 영상 ID, 새로고침 횟수·간격 정보와 선택적인 본영상 재생 위치를 chrome.storage.session에 보관합니다. 위치 복원이 완료되면 저장한 위치를 삭제하며 같은 영상의 누적 횟수는 유지합니다. 브라우저 재시작, 확장 프로그램 업데이트·다시 로드 시 삭제되는 세션 메모리이며, 탭을 닫으면 해당 탭의 상태도 삭제합니다. 위 웹 기록·웹사이트 콘텐츠 공개 및 처리방침에 이 처리를 반영합니다.

실제 대시보드의 항목 설명이 달라졌거나 코드를 변경했다면 해당 정의와 최종 동작을 확인하여 수정하세요. 이 항목들은 심사 결과를 보장하지 않습니다.

데이터 사용 확인 문항
현재 패키지에는 사용자 데이터를 판매하거나 기능과 무관하게 전송하는 코드, 신용도 판단·대출 관련 용도로 사용하는 코드가 없습니다. 게시자는 실제 운영과 지원 업무를 포함하여 각 확인 문항이 사실인지 확인한 뒤 직접 체크해야 합니다. 코드 검토만으로 게시자 본인의 외부 운영 관행을 대신 인증할 수는 없습니다.

심사 참고 메모
현재 보고 있는 Chrome 창의 활성 YouTube 영상 탭에서 광고를 감지하면 영상당 설정한 한도까지 최소 3초 간격으로 새로고침합니다. 한도는 기본 3회, 설정 범위는 1~10회이며 같은 탭의 현재 영상에 시도 횟수가 누적됩니다. 본영상 복원 후에도 횟수는 유지하고 새 영상으로 이동하면 새 한도를 사용합니다. 횟수 변경은 다음 시도부터 적용하며 한도를 늘리면 같은 영상에서 추가 시도할 수 있습니다. 한도를 다 쓴 뒤에도 광고가 계속되면 광고 플레이어 내부의 표시되고 활성화된 건너뛰기 버튼만 클릭합니다. 버튼의 위치와 클릭 가능 상태를 확인하고 Chrome Debugger Input으로 마우스 입력을 전달합니다. 화면에 아직 표시되지 않았거나 사용할 수 없는 버튼은 클릭하지 않습니다. 팝업에서 끄면 새로고침, 재생 위치 복원과 자동 클릭을 중지합니다. 새로고침이 광고를 없앤다고 보장하지 않으며, 광고 영상을 강제로 탐색하지 않습니다. 본영상으로 돌아온 경우에만 마지막으로 확인한 본영상 재생 위치 복원을 시도합니다.
1.0.2 최종 횟수 설정 정책은 Node 검증 81개(worker 46개, 콘텐츠 스크립트 21개, 배포 14개)와 격리 Chromium·실제 MV3 확장의 통합 검증 10개를 통과했습니다. 통합 검증의 YouTube HTTP 요청은 모두 로컬 테스트 페이지로 대체했습니다. 별도로 2026-10-28 13:55~13:58(KST)에 최종 소스와 실행 중 확장 소스의 해시가 일치하는 상태에서 실제 광고 1건을 관찰했습니다. 15.041초 광고의 3.744초 시점에 첫 자동 새로고침, 이어진 6.041초 광고의 1.285초 시점에 두 번째 자동 새로고침이 실행됐으며 간격은 3,103ms였습니다. 이후 새 문서에서 광고 클래스가 한 번도 나타나지 않고 223.381초 본영상이 1.71332초까지 진행됐습니다. 설정 한도 3회 중 2회에서 광고가 없어져 세 번째 새로고침은 실행하지 않았습니다. 외부의 수동 새로고침·건너뛰기·CDP 입력은 사용하지 않았습니다.
이 실제 관찰에서는 건너뛰기 버튼 경로와 중간 광고 뒤 재생 위치 복원은 관찰하지 못했으며 해당 동작은 로컬 테스트 페이지의 통합 검증으로 확인했습니다. 다른 영상 3개에서는 약 40초 뒤 YouTube 재생 오류가 관찰됐으며 확장이 원인인지 확인하지 못했습니다. 실제 성공은 위 1건의 범위이며 광고 제거를 보장하지 않습니다. 초기 1회 새로고침 정책으로 탐색한 실제 광고 2건에서는 광고가 재노출됐고 6초 광고가 15초 광고로 바뀐 경우도 있었으므로 최종 횟수 설정 정책의 결과와 구분합니다.
이전 1.0.1은 실제 31초 광고에서 약 5.23초에 브라우저 입력으로 버튼을 눌러 본영상으로 복귀한 성공 1건이 있었고, 2026-10-23 대시보드·스토어에서 비공개 테스터 게시를 확인했습니다. 1.0.0의 스크립트 클릭 방식은 실제 광고에서 실패했습니다. 이 이전 버전의 결과는 1.0.2의 증거와 분리합니다. 1.0.2는 스토어 제출 준비 중이며 증거 범위는 store/verification.txt에 기록합니다.

게시자가 직접 입력할 정보
• 실제 게시자 이름 또는 표시 이름
• 연락 가능한 이메일 및 계정 확인 정보
• 공개된 개인정보 처리방침 HTTPS 주소
• 실제 지원 연락처 또는 지원 URL을 사용하려는 경우 해당 주소
이 문서에는 임의의 신원이나 이메일을 넣지 않았습니다. 공개 개인정보처리방침 주소는 저장소의 GitHub Pages 주소이며 최신 정책이 게시됐는지 제출 전에 확인합니다.
