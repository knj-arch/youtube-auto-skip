# 유튜브 자동 건너뛰기

PC용 Chrome에서 유튜브 광고의 **건너뛰기 버튼이 표시되고 클릭할 수 있을 때** 자동으로 누르는 확장 프로그램입니다. 현재 보고 있는 Chrome 창의 활성 YouTube 영상(`/watch`) 탭에서 작동하도록 제한합니다. 설치 후 기본값은 켜짐이며, 확장 프로그램 아이콘에서 끄거나 다시 켤 수 있습니다.

**1.0.1의 브라우저 입력 방식에서 실제 광고 자동 건너뛰기 1건을 확인했습니다.** 31초 광고의 버튼을 약 5.23초에 자동으로 눌렀고 본문 영상 재생으로 복귀했습니다. 최종 SPA·정리 처리 보완은 통합 검증 13개와 코드·배포 검증 31개를 통과했습니다. 최종 파일의 추가 실제 광고 탐색에서는 건너뛰기 버튼이 나타나지 않았으므로 이 탐색을 성공으로 계산하지 않았습니다. 이전 1.0.0의 스크립트 클릭 방식은 실제 광고에서 실패했습니다. 자세한 결과는 [검증 기록](store/verification.txt)에 있습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `youtube-auto-skip` 폴더를 선택합니다. `manifest.json`이 바로 들어 있는 폴더여야 합니다.
5. 이미 열려 있던 유튜브 탭은 새로고침합니다.
6. 필요하면 Chrome 도구 모음의 퍼즐 아이콘에서 **유튜브 자동 건너뛰기**를 고정합니다.

폴더는 설치 후에도 같은 위치에 보관해야 합니다. ZIP 파일을 받은 경우 먼저 압축을 풀고 설치하세요.

## 동작 범위

- 현재 보고 있는 Chrome 창의 활성 `https://www.youtube.com/watch` 영상 탭에서 동작합니다. 다른 탭이나 다른 프로그램을 보고 있을 때는 자동 클릭하지 않습니다.
- 영상 시작 전이나 재생 중에 광고 건너뛰기 버튼이 나타나면 클릭합니다.
- 광고 플레이어 안에서 실제 화면에 표시되고 클릭 가능한 건너뛰기 버튼만 클릭합니다. 버튼 위치를 확인한 뒤 Chrome Debugger의 `Input.dispatchMouseEvent`로 마우스 입력을 전달합니다.
- 유튜브 안에서 영상을 바꾸거나 전체 화면으로 전환해도 계속 감지합니다.
- 끄기/켜기 설정은 이 브라우저에 저장되며 열려 있는 유튜브 탭에도 적용됩니다.
- 건너뛰기 버튼이 없는 광고와 버튼이 활성화되기 전 대기 시간은 그대로 유지됩니다.
- 광고 차단이나 영상 재생 시간 변경 기능은 없습니다.

유튜브 화면 구조가 바뀌면 콘텐츠 스크립트와 백그라운드의 버튼 확인 코드를 수정해야 할 수 있습니다. 실제 광고는 계정·지역에 따라 달라지므로 본인 브라우저에서 동작을 확인하세요. YouTube 탭에서 개발자 도구를 열었거나 Chrome의 디버깅 알림에서 중지한 경우 디버거 연결이 끊겨 해당 자동 클릭이 진행되지 않을 수 있습니다.

## 권한과 데이터

`storage` 권한은 켜기/끄기 설정 한 개를 현재 기기에 저장하는 데 사용합니다. `debugger` 권한은 표시되고 활성화된 광고 건너뛰기 버튼에 Chrome이 제공하는 마우스 입력을 보내는 데 사용합니다. 버튼 확인과 클릭을 위해 해당 YouTube 영상 탭에 잠시 연결하며 클릭 처리가 끝나면 연결을 해제합니다.

**`debugger`는 넓은 권한입니다.** Chrome은 페이지 디버거 접근 및 **모든 웹사이트의 데이터 읽기·변경** 경고를 표시할 수 있습니다. 권한 자체의 범위가 YouTube로 한정되는 것은 아닙니다. 이 확장 프로그램의 코드는 현재 보고 있는 YouTube 영상 탭만 대상으로 제한합니다. Chrome의 디버깅 알림이 클릭 처리 중 잠시 표시될 수 있습니다.

현재 탭이 대상인지 확인하기 위한 주소·활성 상태, 플레이어·버튼 상태와 좌표는 기기 안에서 처리합니다. 외부 서버로 전송하거나 시청 기록, 쿠키, 계정 정보 또는 사용자의 입력을 기록하는 기능은 없습니다. 영구 클릭 로그도 저장하지 않습니다. 별도 빌드나 패키지 설치 없이 위 파일을 바로 로드하면 됩니다.

Chrome의 공식 [확장 프로그램 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked), [Debugger API](https://developer.chrome.com/docs/extensions/reference/api/debugger), [권한 경고 안내](https://developer.chrome.com/docs/extensions/reference/permissions-list#debugger)를 참고했습니다.

## Git push로 배포

저장소: https://github.com/knj-arch/youtube-auto-skip

공개 개인정보 처리방침: https://knj-arch.github.io/youtube-auto-skip/

`main` 브랜치에 관련 파일을 push하면 GitHub Actions가 아래 작업을 수행합니다.

- `store/privacy.html` 변경: 개인정보 처리방침을 GitHub Pages에 게시합니다.
- 확장 프로그램 코드·아이콘 변경: 업로드용 ZIP을 만들고 Actions 실행의 첨부 파일로 저장합니다.
- 웹 스토어 API 설정이 연결된 경우: ZIP 업로드 후 심사에 제출합니다. 승인되면 기존 배포 범위로 게시됩니다.

처음에는 개발자 등록과 첫 스토어 항목 작성이 필요합니다. GitHub 저장소 설정에도 API 연결 정보를 한 번 입력해야 합니다. 자세한 순서는 `store/automation-cws.txt`와 `store/install-and-submit.txt`에 있습니다.

현재 최초 1.0.0 제출은 검토 대기 이력이 있습니다. 1.0.1은 실제 광고 자동 건너뛰기 성공을 확인한 뒤 기존 심사를 취소하고 새 패키지로 교체합니다. 자동화는 기존 심사를 취소하거나 교체하지 않습니다. 권한이 추가된 버전은 대시보드의 `debugger` 사유와 데이터 공개 내용도 함께 갱신해야 합니다.

소스의 기본 버전은 `manifest.json`의 세 자리 버전이며, CI에서 GitHub 실행 번호를 네 번째 숫자로 추가합니다. 예를 들어 소스 `1.0.1`과 실행 번호 `12`는 스토어 패키지 `1.0.1.12`가 됩니다. 새 push마다 새 버전이 만들어집니다. API 연결 전에는 스토어 업로드를 건너뛰고 ZIP 생성까지만 진행합니다.

업로드 패키지를 로컬에서 만들려면 PowerShell에서 `./build-store-package.ps1`을 실행합니다. ZIP은 `dist/`에 생성되며 `manifest.json`이 압축 파일 최상위에 위치합니다. 이미지 및 제출 문서는 패키지에 포함되지 않습니다.

실제 광고 검증에 사용한 `.verification/` 산출물, 브라우저 프로필, 계정 정보, 스크린샷의 개인 정보 및 API 비밀정보는 공개 저장소나 배포 패키지에 포함하지 않습니다.
