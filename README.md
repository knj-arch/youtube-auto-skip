# 유튜브 자동 건너뛰기

PC용 Chrome에서 유튜브 광고를 감지하면 **설정한 횟수까지 새로고침하고, 한도에 도달해도 광고가 계속되면 건너뛰기 버튼을 자동으로 누르는** 확장 프로그램입니다. 새로고침 한도는 기본 3회이며 팝업에서 1~10회로 바꿀 수 있습니다. 현재 보고 있는 Chrome 창의 활성 YouTube 영상(`/watch`) 탭에서 작동하도록 제한합니다. 설치 후 기본값은 켜짐이며, 확장 프로그램 아이콘에서 끄거나 다시 켤 수 있습니다.

현재 소스는 **1.0.2이며 구현과 로컬 검증을 완료하고 스토어 제출을 준비 중입니다.** 새로고침으로 본영상이 나오는지는 YouTube의 광고 제공에 따라 달라지며 광고 제거를 보장하지 않습니다. 2026년 10월 23일 확인한 스토어 게시 버전은 1.0.1이며 비공개 테스터에게 배포돼 있었습니다.

현재 횟수 설정 정책과 배포 코드는 Node 검증 90개와 격리 Chromium·실제 MV3 확장의 통합 검증 10개를 통과했습니다. 별도로 실제 광고 1건에서 자동 새로고침 2회 후 본영상 재생을 확인했습니다. 설정 한도는 3회였지만 광고가 없어지자 세 번째 새로고침은 실행하지 않았습니다. 통합 검증은 로컬 테스트 페이지를 사용하며 실제 광고 관찰과 구분합니다. 자세한 결과와 한계는 [검증 기록](store/verification.txt)에 있습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `youtube-auto-skip` 폴더를 선택합니다. `manifest.json`이 바로 들어 있는 폴더여야 합니다.
5. 이미 열려 있던 유튜브 탭은 새로고침합니다.
6. 필요하면 Chrome 도구 모음의 퍼즐 아이콘에서 **유튜브 자동 건너뛰기**를 고정합니다.

폴더는 설치 후에도 같은 위치에 보관해야 합니다. ZIP 파일을 받은 경우 먼저 압축을 풀고 설치하세요.

## 동작 범위

- 현재 보고 있는 Chrome 창의 활성 `https://www.youtube.com/watch` 영상 탭에서 동작합니다. 다른 탭이나 다른 프로그램을 보고 있을 때는 자동 새로고침이나 클릭을 하지 않습니다.
- 영상 시작 전이나 재생 중에 광고를 감지하면 설정한 한도까지 최소 3초 간격으로 새로고침합니다. 기본 한도는 3회이며 팝업에서 1~10 사이의 정수로 바꿀 수 있습니다.
- 시도 횟수는 같은 탭의 현재 영상에 누적됩니다. 본영상으로 돌아와도 누적 횟수는 유지하며, 새 영상으로 이동하면 새 한도를 사용합니다.
- 한도를 다 쓴 뒤에도 광고가 나오면 표시되고 클릭 가능한 건너뛰기 버튼을 기다렸다가 누릅니다. 버튼이 없는 광고는 그대로 재생됩니다.
- 횟수 변경은 자동 저장되며 다음 시도부터 적용됩니다. 한도를 늘리면 같은 영상에서도 늘어난 한도 안에서 추가로 시도할 수 있습니다.
- 광고 플레이어 안에서 실제 화면에 표시되고 클릭 가능한 건너뛰기 버튼만 클릭합니다. 버튼 위치를 확인한 뒤 Chrome Debugger의 `Input.dispatchMouseEvent`로 마우스 입력을 전달합니다.
- 유튜브 안에서 영상을 바꾸거나 전체 화면으로 전환해도 계속 감지합니다.
- 끄기/켜기와 최대 새로고침 횟수 설정은 이 브라우저에 저장되며 열려 있는 유튜브 탭에도 적용됩니다.
- 광고가 아닌 구간에서 마지막으로 확인한 본영상 재생 위치가 있으면, 새로고침 후 같은 본영상으로 돌아왔을 때 복원을 시도합니다. 라이브 영상이나 재생 길이가 불명확한 경우에는 복원을 생략합니다.
- 새로고침은 광고 없이 본영상으로 넘어가는 것을 보장하지 않습니다. 광고가 다시 나오거나 더 길어질 수 있으며 재생 위치 복원도 YouTube 플레이어 상태에 따라 생략되거나 지연될 수 있습니다.

유튜브 화면 구조가 바뀌면 콘텐츠 스크립트와 백그라운드의 버튼 확인 코드를 수정해야 할 수 있습니다. 실제 광고는 계정·지역에 따라 달라지므로 본인 브라우저에서 동작을 확인하세요. YouTube 탭에서 개발자 도구를 열었거나 Chrome의 디버깅 알림에서 중지한 경우 디버거 연결이 끊겨 해당 자동 클릭이 진행되지 않을 수 있습니다.

## 권한과 데이터

`storage` 권한은 켜기/끄기(`enabled`)와 최대 새로고침 횟수(`maxReloads`) 설정을 `chrome.storage.local`에 저장하고, 새로고침 한도·간격 확인과 재생 위치 복원에 필요한 임시 상태를 `chrome.storage.session`에 보관하는 데 사용합니다. 임시 상태는 탭별 현재 영상 ID, 새로고침 시도 횟수·간격 정보와 선택적인 본영상 재생 위치입니다. 확장 프로그램만 접근할 수 있는 Chrome 세션 메모리에 보관하며 탭을 닫거나 브라우저를 다시 시작하거나 확장 프로그램을 업데이트·다시 로드하면 삭제됩니다. 재생 위치 복원이 완료되면 저장한 위치는 삭제하고, 시도 횟수는 같은 영상을 보는 동안 유지합니다.

`debugger` 권한은 표시되고 활성화된 광고 건너뛰기 버튼에 Chrome이 제공하는 마우스 입력을 보내는 데 사용합니다. 버튼 확인과 클릭을 위해 해당 YouTube 영상 탭에 잠시 연결하며 클릭 처리가 끝나면 연결을 해제합니다. 1.0.2에서 추가하는 권한은 없습니다.

**`debugger`는 넓은 권한입니다.** Chrome은 페이지 디버거 접근 및 **모든 웹사이트의 데이터 읽기·변경** 경고를 표시할 수 있습니다. 권한 자체의 범위가 YouTube로 한정되는 것은 아닙니다. 이 확장 프로그램의 코드는 현재 보고 있는 YouTube 영상 탭만 대상으로 제한합니다. Chrome의 디버깅 알림이 클릭 처리 중 잠시 표시될 수 있습니다.

현재 탭이 대상인지 확인하기 위한 주소·활성 상태, 플레이어·버튼 상태와 좌표 및 재생 위치는 기기 안에서 처리합니다. 임시 영상 상태를 방문 URL 목록이나 시청 기록으로 누적하지 않으며 외부 서버로 전송하지 않습니다. 쿠키, 계정 정보 또는 사용자의 입력을 수집하거나 영구 클릭 로그를 저장하는 기능은 없습니다. 별도 빌드나 패키지 설치 없이 위 파일을 바로 로드하면 됩니다.

Chrome의 공식 [확장 프로그램 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked), [Debugger API](https://developer.chrome.com/docs/extensions/reference/api/debugger), [권한 경고 안내](https://developer.chrome.com/docs/extensions/reference/permissions-list#debugger)를 참고했습니다.

## 검증

2026년 10월 28일 현재 횟수 설정 정책의 Node 검증 81개(worker 46개, 콘텐츠 스크립트 21개, 배포 14개)를 모두 통과했습니다. 저장소 폴더에서 다음 명령으로 재현할 수 있습니다.

```powershell
node --test tests/*.test.mjs tests/*.test.cjs
```

격리 Chromium에 실제 MV3 확장을 로드한 통합 검증 10개도 모두 통과했습니다. 기본 3회·최소 3초 간격, 팝업의 1회·5회 설정 저장 및 다시 열기, 설정에 따른 실제 새로고침 횟수와 잘못된 수치 거절을 확인했습니다. 3회 새로고침 중 본영상 3초 위치를 유지하고 복원 완료 확인 후 임시 위치만 삭제하는 과정도 통과했습니다. 설정 끄기, 다른 경로와 백그라운드 탭에서의 처리 제한도 확인했습니다. 이 검증은 실제 worker, `chrome.storage.session`, `chrome.tabs.reload`와 Debugger 입력을 실행하지만 모든 YouTube HTTP 요청을 로컬 테스트 페이지로 대체합니다.

2026년 10월 28일 13:55~13:58(KST)에 최종 횟수 설정 정책을 실제 YouTube 광고에서 관찰했습니다. 15.041초 광고가 3.744초 재생된 시점에 첫 번째 자동 새로고침, 이어진 6.041초 광고가 1.285초 재생된 시점에 두 번째 자동 새로고침이 실행됐습니다. 새로고침 간격은 3,103ms였습니다. 다음 문서에서는 광고 클래스가 한 번도 나타나지 않았고 223.381초 본영상이 1.71332초까지 재생됐습니다. 한도 3회 중 2회에서 본영상이 나오자 추가 새로고침은 실행하지 않았습니다. 실행 중 확장 소스와 검증 대상 파일의 해시 일치를 확인했으며 외부의 수동 새로고침·건너뛰기·CDP 입력은 사용하지 않았습니다.

이 실제 관찰에서는 건너뛰기 버튼을 누르는 경로와 중간 광고 뒤 재생 위치 복원은 관찰하지 못했습니다. 해당 동작은 로컬 테스트 페이지의 통합 검증으로 확인했습니다. 다른 영상 3개에서는 약 40초 뒤 YouTube 재생 오류가 관찰됐으며 확장이 원인인지는 확인하지 못했습니다. 실제 성공은 위 1건의 범위이며 광고 제거를 보장하지 않습니다.

초기 1회 정책은 Node 검증 64개(worker 36개, 콘텐츠 스크립트 14개, 배포 14개)와 격리 Chromium 통합 검증 6개를 통과했습니다. 이는 현재 횟수 설정을 추가하기 전 정책의 이력입니다. 이후 초기 정책으로 별도 탐색한 실제 광고 2건에서는 자동 새로고침은 작동했지만 광고가 재노출됐고, 6초 광고가 15초 광고로 바뀐 경우도 관찰했습니다. 건너뛰기 버튼이 없어 이 탐색의 실제 건너뛰기 성공은 확인하지 못했습니다. 이 초기 정책의 결과와 최종 횟수 설정 정책의 성공 1건은 구분합니다. 1.0.2는 스토어 제출 준비 중이며 검증 결과를 스토어 배포 성공으로 해석하지 않습니다.

이전 1.0.1의 브라우저 입력 방식에서는 실제 31초 광고의 버튼을 약 5.23초에 자동으로 눌러 본영상 재생으로 돌아온 성공 1건이 있었습니다. 그 뒤 1.0.1 최종 SPA·정리 보완은 통합 검증 13개와 코드·배포 검증 31개를 통과했으나, 당시 최종 파일의 추가 실제 광고 탐색에서는 건너뛰기 버튼이 나타나지 않았습니다. 이 이력은 1.0.2의 새로고침 효과를 입증하지 않습니다. 1.0.0의 스크립트 클릭 방식은 실제 광고에서 실패했습니다.

## Git push로 배포

저장소: https://github.com/knj-arch/youtube-auto-skip

공개 개인정보 처리방침: https://knj-arch.github.io/youtube-auto-skip/

`main` 브랜치에 관련 파일을 push하면 GitHub Actions가 아래 작업을 수행합니다.

- `store/privacy.html` 변경: 개인정보 처리방침을 GitHub Pages에 게시합니다.
- 확장 프로그램 코드·아이콘 변경: 업로드용 ZIP을 만들고 Actions 실행의 첨부 파일로 저장합니다.
- 웹 스토어 API 설정이 연결된 경우: ZIP 업로드 후 심사에 제출합니다. 승인되면 기존 배포 범위로 게시됩니다.

처음에는 개발자 등록과 첫 스토어 항목 작성이 필요합니다. GitHub 저장소 설정에도 API 연결 정보를 한 번 입력해야 합니다. 자세한 순서는 `store/automation-cws.txt`와 `store/install-and-submit.txt`에 있습니다.

1.0.0 심사를 취소한 뒤 실제 광고 자동 건너뛰기를 확인한 1.0.1로 교체해 제출했습니다. 2026년 10월 23일 실제 대시보드와 스토어 페이지에서 1.0.1의 비공개 테스터 게시를 확인했습니다. 현재 소스인 1.0.2는 아직 재심사에 제출하지 않았습니다. 자동화는 기존 심사를 취소하거나 교체하지 않습니다. 기능이나 데이터 처리 방식이 바뀌면 스토어 설명·권한 사유·개인정보 공개 내용도 최종 코드에 맞게 함께 갱신해야 합니다.

소스의 기본 버전은 `manifest.json`의 세 자리 버전이며, CI에서 GitHub 실행 번호를 네 번째 숫자로 추가합니다. 예를 들어 소스 `1.0.1`과 실행 번호 `12`는 스토어 패키지 `1.0.1.12`가 됩니다. 새 push마다 새 버전이 만들어집니다. API 연결 전에는 스토어 업로드를 건너뛰고 ZIP 생성까지만 진행합니다.

업로드 패키지를 로컬에서 만들려면 PowerShell에서 `./build-store-package.ps1`을 실행합니다. ZIP은 `dist/`에 생성되며 `manifest.json`이 압축 파일 최상위에 위치합니다. 이미지 및 제출 문서는 패키지에 포함되지 않습니다.

실제 광고 검증에 사용한 `.verification/` 산출물, 브라우저 프로필, 계정 정보, 스크린샷의 개인 정보 및 API 비밀정보는 공개 저장소나 배포 패키지에 포함하지 않습니다.
